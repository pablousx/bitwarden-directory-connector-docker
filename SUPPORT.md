# Soporte

Consulte primero el [README](README.md) y los issues existentes. Para un problema reproducible, use el formulario de bug; para una mejora, el de funcionalidad. Para preguntas de uso, abra un issue explicando qué intentó y dónde se atascó.

Incluya versión de la imagen o digest, proveedor, arquitectura, versiones de Docker/Compose y un ejemplo mínimo con datos ficticios. Redacte credenciales, nombres de personas, dominios privados y resultados del directorio. No adjunte su volumen ni su `data.json` real.

El soporte de este contenedor comunitario es voluntario y no tiene plazo garantizado. Los problemas propios de Bitwarden pueden requerir consultar su documentación y soporte oficial. Los asuntos de seguridad siguen el proceso privado de [SECURITY.md](SECURITY.md).
